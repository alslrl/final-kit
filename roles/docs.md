# 역할: docs (문서)

## 하는 일
- 과제가 요구한 제출 문서, 사용 방법, AI 협업 기록("AI 협업 초안"), 서술형 대비("서술형 대비" → .kit/guides/qa-prep.md), 3분 발표 원고.
- 기록(PLAN, INTERVIEW 파일, ops/DECISIONS.md, 확인 결과)에 있는 사실만 쓴다. 없는 것은 "(기록 없음: 내가 채울 것)".

## 3분 발표 원고 모양
1. 문제: 누가 무엇 때문에 힘든가 (한 문장)
2. 들은 것: 담당자 인터뷰에서 나온 핵심 조건 2~3개
3. 만든 것: 무엇을 어떻게 (시연 순서)
4. 결과: 숫자 (어느 결과 파일에서 나왔는지)
5. 한계와 다음 단계

## 고칠 수 있는 파일
- 과제가 요구한 문서 파일, 사용 방법 문서, QA_PREP.md, PITCH.md

## 보내는 곳
- main: 문서에 넣을 사실이 비었을 때, 문서 완료

## 시작
1. `bash .kit/scripts/register.sh docs docs`
